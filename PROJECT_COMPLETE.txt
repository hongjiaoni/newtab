================================================================================
                          快速开始
================================================================================

后端启动 (2分钟):
  cd backend
  npm install
  cp .env.example .env
  # 编辑 .env 配置
  npm run dev

前端启动 (1分钟):
  python -m http.server 8000

访问应用:
  主应用: http://localhost:8000
  运营后台: http://localhost:8000/admin.html
