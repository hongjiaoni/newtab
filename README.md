# NewTab Project

这是一个基于 Web 的自定义新标签页项目，支持 Google 登录、云端数据同步和运营后台管理。

## 快速开始

请查看 [DEPLOY.md](DEPLOY.md) 了解如何安装和运行。

## 目录结构

- `public/`: 前端代码（HTML, CSS, JS）
    - `admin/`: 运营后台代码
- `server.js`: 后端服务器代码
- `database.js`: 数据库管理
- `docs/archive/`: 旧文档存档

## 技术栈

- Backend: Node.js + Express + SQLite
- Frontend: Vanilla JS + CSS
